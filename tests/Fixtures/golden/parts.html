    Claude — web and desktopregisters itself
    1. Open Claude's settings and find the connectors section. Choose to add a custom or remote connector — the wording moves between releases, but it is the one that asks for a URL rather than offering a directory of ready-made integrations.
    2. Paste the MCP server URL above as the only value it asks for. Claude finds the authorization server from it.
    3. Claude opens this site in a browser tab. Sign in if you are not already, then approve the request on the consent screen.
    4. The tab closes itself and the connector appears as connected. Its tools are then offered in a conversation, one per published ability.

    Registers itself on first contact, so there is nothing to create here and nothing to paste back.

    Claude Codeone command
    1. Run the add command in a terminal, naming the server whatever you will want to see in the tool list:In a terminalclaude mcp add --transport http example-site 'https://example.test/mcp'
    2. Start Claude Code and type /mcp. The server is listed as needing authentication; choose it and a browser opens on the consent screen.
    3. Approve there, and the terminal picks the session up. The authorisation is kept, so this is a first-connection step rather than a daily one.

    Registers itself on first contact, so there is nothing to create here and nothing to paste back.

    ChatGPTavailability varies by plan
    1. Open the connectors section of ChatGPT's settings and add a custom connector. Custom MCP connectors are not offered on every plan; if the option is absent, that is the reason.
    2. Paste the MCP server URL and choose OAuth as the authentication method.
    3. Approve the request on the consent screen this site opens.

    If it will not accept a self-registering connector, create a client by hand under Applications and give ChatGPT the identifier and secret shown there once.

    Cursor, VS Code and other editorsa JSON entry
    1. These clients keep their MCP servers in a JSON configuration file, reachable from the MCP section of their settings.
    2. Add one entry with the MCP server URL and an HTTP transport:In the MCP configuration file{ "mcpServers": { "example-site": { "type": "http", "url": "https://example.test/mcp" } } }
    3. Reload the window. The server appears in the MCP list, and the first call opens the consent screen in a browser.

    Editors differ on the key naming — some want "type": "http", some "transport": "http". If the server never appears, that key is the first thing to check.
